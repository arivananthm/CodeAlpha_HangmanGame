# CodeAlpha Hangman Game

## About

This is a simple text-based Hangman game developed using Python
as part of the CodeAlpha Python Programming Internship.

## Features

- Randomly selects a word from a list of 5 words
- Allows the player to guess one letter at a time
- Maximum of 6 incorrect guesses
- Displays guessed letters
- Detects win and game-over conditions

## Technologies Used

- Python
- Random module
- Lists
- Strings
- While loop
- For loop
- If-else statements
- User input

## How to Run

Run the following command:

```bash
python hangman.py
